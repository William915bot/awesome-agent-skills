## 工作流程
`Manual Trigger → GitHub Public Search + HN Search → Merge → Evidence Guard → AI Agent → 人工審稿`

## 安全原則
尚未在你的 n8n 執行、尚未接真實 API Credential；匯入後須測試。開源來源以**外部連結索引**保存，不表示複製/已 fork/已安裝。所有社群發文保留人工批准。

## 後續
